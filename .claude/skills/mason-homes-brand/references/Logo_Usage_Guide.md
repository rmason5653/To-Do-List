# MASON HOMES LOGO USAGE GUIDE

**Version 3.0 | Ryan Mason Brand Kit (aligned with Palette v3.1)**

This document defines how Mason Homes logos can and cannot be used. Follow these rules on every project. No exceptions.

---

## THE LOGO VARIANTS

### Vertical Stacked (Logo mark above wordmark)

| File Prefix       | Background | Primary Use                              |
|-------------------|------------|-------------------------------------------|
| Vertical_WhiteBG  | White      | Documents, letterhead, external assets    |
| Vertical_DarkBG   | Midnight   | END CARD (primary), social, presentations |
| Vertical_RedBG    | Red grad.  | Marketing, event signage, promotional     |

### Horizontal (Logo mark left of wordmark)

| File Prefix          | Background | Primary Use                              |
|----------------------|------------|-------------------------------------------|

| Horizontal_DarkBG    | Midnight   | Alternate end card, wide banners          |
| Horizontal_RedBG     | Red grad.  | Marketing, banners, promotional           |

---

## VIDEO RULES

1. The logo appears ONLY on the end card. Never as a watermark on the body of the video.
2. The default end card logo is **Vertical_DarkBG** (Logo 2).
3. For wide-format end cards, use **Horizontal_DarkBG** (Logo 5).
4. End card background is always solid Midnight (#0B0B0D). The logo file already has the correct background baked in.
5. End card duration is 1.5 to 2 seconds with a single sub-bass impact.

---

## CLEAR SPACE

Always maintain a minimum clear space around the logo equal to the height of the letter "M" in the wordmark. No other elements (text, images, icons, borders) should enter this zone.

```
        _______________
       |    M height   |
       |   ___         |
       |  |   |        |
  M    |  | M |  LOGO  |   M
height |  |___|        | height
       |               |
       |_______________|
       |    M height   |
```

---

## MINIMUM SIZE

- **Digital:** The logo should never appear smaller than 120px wide (horizontal) or 80px wide (vertical).
- **Print:** The logo should never appear smaller than 1 inch wide (horizontal) or 0.75 inches wide (vertical).

Below these sizes, the M-mark detail is lost and the wordmark becomes unreadable.

---

## DO

- Use the logo files exactly as provided (correct colors, correct proportions)
- Place the logo on the approved backgrounds (midnight, white, or red gradient as provided)
- Use the vertical variant when space allows stacking
- Use the horizontal variant when width is constrained or the format is wide (banners, headers)
- Maintain clear space on all sides

---

## DO NOT

- **Stretch, skew, or rotate** the logo in any direction
- **Change the colors** of any element (the M-mark, "MASON," or "HOMES")
- **Add effects** (drop shadows, glows, bevels, outlines, gradients not in the original)
- **Place on busy backgrounds** without the provided background fill (dark, white, or red)
- **Place on pure black (#000000)** -- always use Midnight (#0B0B0D)
- **Use Logo 1 or Logo 6 as end cards** -- those are for documents and external assets only
- **Animate the logo** beyond a simple fade-in or scale-up (2-3 frames max)
- **Recreate or redraw** the logo in any software -- always use the provided files
- **Add text, taglines, or other elements** inside the clear space zone
- **Use the logo as a watermark** on the body of videos

## ICON-ONLY USE (M EMBLEM)

The M emblem — the abstract building mark without any wordmark — is its own asset inside the brand kit. Use it for small-format identifiers, profile pictures, favicons, watermarks, and anywhere a full logo would be too large or too literal.

All M emblem files live in `01_Logos/M_Emblem_Only/`.

### Variant guide

**Transparent backgrounds (use on any background):**
- `MasonM_White_Transparent.png` — white M on transparent, for dark backgrounds
- `MasonM_Red_Transparent.png` — Mason Red M on transparent, for light backgrounds
- Both include `_1024.png` versions sized for profile pictures

**Solid backgrounds (ready to drop in):**
- `MasonM_Red_on_Midnight` — Mason Red on v3.1 Midnight. RECOMMENDED Instagram profile pic.
- `MasonM_White_on_Midnight` — White on v3.1 Midnight. Alternate profile pic.
- `MasonM_Red_on_Bone` — Mason Red on v3.1 Bone White. Documents, light UI.
- `MasonM_Red_on_White` — Mason Red on pure white. Legacy documents.

**Designer-delivered variants (full file sets: PNG, JPG, PDF, AI, EPS):**
- `MasonM_RedGradient_on_Black` — marketing, merchandise
- `MasonM_White_on_Red` — marketing, bold punch
- `MasonM_White_on_DarkRed` — marketing, alternative
- `MasonM_White_on_RedGradient` — marketing, premium look

### When to use the M emblem

- Instagram, TikTok, YouTube profile picture
- Website favicon (browser tab icon)
- Video watermarks (only if a full end card does not fit the format)
- App icons, bookmark icons
- Small-format merchandise (pins, patches, embroidery corners)
- Stamp graphics at the end of presentations or documents
- Email signature icon (next to contact info)
- Social media avatar on any platform

### When NOT to use the M emblem

- As a replacement for the full logo on official business documents, contracts, or external-facing marketing where the company name needs to be legible
- As the primary mark on a business card (use the full logo; the emblem is only appropriate if paired with the name spelled out elsewhere)
- On video end cards (use the full Vertical_DarkBG or Horizontal_DarkBG logo)
- Stretched, skewed, or rotated

### Minimum size

- Digital: 32px (favicon minimum), 48px for profile pictures
- Print: 0.5 inches minimum

### Color discipline

The M emblem follows the same color rules as the full logo. Never recolor it outside the approved variants. If a context calls for a color that is not in the kit, request a new variant from the designer using the `.ai` source files — do not recolor in Photoshop.

## FILE FORMATS

| Format | Use Case                                      |
|--------|------------------------------------------------|
| .png   | Digital use, social media, presentations, web  |
| .jpg   | Email, documents where transparency not needed |
| .pdf   | Print-ready, high-quality presentations        |
| .ai    | Designer edits only (Adobe Illustrator source) |
| .eps   | Print production, signage, merchandise         |

RGB versions are for digital. CMYK versions (in Source_Files) are for print production only.
